## 问题清单

### P1（必修）

**A-1 `ocdup watch --halt` 在 Ctrl+C 恰落采样窗口时把目标留在 halted**
`src/Ocdup/Cli/WatchCli.cs:183-193`：finally 里 resume 用的是**已取消的**采样 ct，
`BackendSession.ExecuteAsync → _channelGate.WaitAsync(ct)` 立即抛 OCE，resume 永远发不到后端。
`RttCli.cs:87-98` 已修过同款（收尾用 `CancellationToken.None`），watch 漏了。
复现：`watch --halt` 运行中，Ctrl+C 落在 halt→mdw 读取之间。类注释（:101）与 help 都承诺「--halt 途中保证 resume」。

### P2（明显缺陷/不一致，全修）

**A-2 BpTools 五工具流量 op 恒为 `"bp"`**
`src/Ocdup/Tools/BpTools.cs:214`（`RunAsync` 硬编码 `op: "bp"`）。后果：
① `BackendSession.ReplaySafeOps` 里的 `"list_breakpoints"`（BackendSession.cs:51）成死代码——
纯读的 list_breakpoints 断链后不自动重放，还收到「命令可能已生效、未重放」的误导文案；
② 流量日志 mcp-traffic.jsonl 的 tool 字段五种工具混写成一个 `bp`。

**A-3 `read_variable` / `write_variable` 不处理非对齐地址**
`src/Ocdup/Tools/SymbolTools.cs:86-91`（read 直接 `mdw {addr} {count}`）与 `:148-149`（write 直接
`mww/mwh {addr}`）。packed struct 里的 u8/u16/u32 落在非对齐地址时 mdw/mww 失败或语义未定义。
同仓先例：`WatchCli.cs:172` 对同一条数据面做了 `addr & ~3` 对齐 + 小端摘字节，read/write_variable 漏了同款。

**A-4 SvdTools.GetLoaded 吞掉解析异常，报错误导**
`src/Ocdup/Tools/SvdTools.cs:229-231`：svd_path 已配置但文件损坏时，read/write_peripheral_register
报「no SVD file is loaded, call load_svd or set svd_path」——用户明明已设 svd_path，真实解析错误不可见；
LoadSvd 同一文件却有完整报错，两条路径行为不一致。

**A-5 SVD 数组寄存器（名含 `[%s]`）永不匹配且无提示**
`src/Ocdup/Backend/SvdFile.cs:70`（name 原样保留 `[%s]`）+ `SvdTools.cs:122-125`（FindRegister 精确比较）。
厂商 SVD 常见 `<dim>` 数组寄存器（`NAME[%s]`）永远查不到，报「has no register」也不提示数组形态。

**A-6 watch CLI 退出码与 burn/verify/rtt 家族错位**
`src/Ocdup/Cli/WatchCli.cs:29,38,49,84,132`：usage/BLOCKED/符号缺失→1，后端丢失→2；
家族约定（BurnCli.cs:79-85）是 0/1/2/3（usage/权限=2、后端/通道=3）。且 watch --help 不写退出码。
watch 隶属 v0.4.3 入库、仍在快速演进期，对齐家族成本低于长期 CI 分流成本。

**A-7 doctor CLI 的 usage 退出码未文档化**
`src/Ocdup/Cli/DoctorCli.cs:57` 实际 usage 错误→2，help（:33-35）只声明 0/1。

**A-8 BackendSession.Invalidate 无条件 Dispose 的竞态**
`src/Ocdup/Backend/BackendSession.cs:196`：A 线程命令失败（channel gate 已释放）到调 Invalidate 之间，
B 线程可 Acquire 出**新**连接并写入 `_client`；A 的 `Interlocked.Exchange` 把 B 的新连接杀掉，
B 得到伪 ObjectDisposedException（写类 op 直接误报「命令可能已生效」）。窗口窄但真实。

### 待真机确认（不擅自改）

**A-9 ParseRegValue 对注释文档化的 atopenocd 形态解析失败**
`src/Ocdup/Tools/Parsing.cs:113-116` 注释声称 atopenocd（0.11.0+dev）输出
`pc (/32): 0x080002ab62`（**10 位 hex**）；`:132` 的 `uint.TryParse` 对它溢出失败 → 该形态下
halt 后核心寄存器行静默缺失。二者必居其一：若真机确实输出 10 位，是解析缺陷（需真机定形态语义——
截断？拼接？）；若是注释笔误（应为 8 位 0x080002ab），只需改注释。**需真机验证，本轮不动。**

### 建议（P3，本轮不改，列出备查）

  把失败结论包在成功形态文本里，无机器可读标记（FlashTools.cs:219-224, MemoryTools.cs:232-234）。
  加结构化标记 = 对外输出契约变更，列建议。

  模型侧无创建链接的手段，纵深防御边界记录在案。

  与 README 面板史为准；包版本号未维护）。

## 核查通过（无需改）

- **注入面**：Tools+Cli 全部命令构造点核过，路径均 `ResolvePath`+`Tcl.Quote`（program/verify_image/
  dump_image/rtt id），地址/计数均为 `Parsing.Hex` 或已校验 int，无未转义内插。
- **Parsing 边界**：无 count=0/负数穿透；2^63/非数字被 TryParseHex 拒；写值按宽度掩码
  （Parsing.HexValue / SvdFile.WriteCommand）。
- **TclRpcClient 帧解析**：半包累积（MemoryStream 整体解码防 UTF-8 切裂）、命令超时同时管写读、
  信号量串行（C1）；**命令超时后 ExecuteAsync 统一 Invalidate 丢弃连接**，不存在残留半响应污染下一条命令。
- **权限矩阵**：`set_permissions` 自授权只能由 ocd.json 的 `allow_set_permissions` 打开（无运行时旁路，
  ConfigTools/OcdConfig.RuntimePatchableKeys 白名单双向对齐）；read_only 总闸覆盖全部写路径
  （memory/flash/erase/exec/raw/set-target/disconnect）；RawCommandPolicy `;` 分段逐段分类 +
  注释段放行，宁多拦不漏拦；bp/rbp/wp/rwp 已归 ExecControl（v0.4.30）。
- **路径白名单**：ResolvePath 基准 ocd.json 目录、GetFullPath 折叠 `..`；IsInsideAny 双前缀判断。
- **进程生命周期**：Windows Job KILL_ON_JOB_CLOSE + ProcessExit 双保险（孤儿进程收口）；
  stdout/stderr 双泵抽干；启动稳定探测 ×3；端口被外部占用如实报告不自作主张。
- **TrafficLog**：文件 2MB 轮转 + 单条 4000 字符截断 + 全吞错，内存/磁盘双有界。
- **并发**：BackendSession 双闸（connect gate + channel gate）串行化，心跳 WaitAsync(0) 让路。
- **ELF/SVD**：strip 后无 symtab → 带指引的 ElfParseException；SVD 集群路径「首点切分+展平前缀」正确
  （"TIM1.PWM.CCR" 可解析）；SvdFile.ParseNumber 的 #二进制/裸 hex 兜底齐全。
- **Flash 语义**：CRC 起不来 = INCONCLUSIVE（burn 与 verify 同一份判据）；reset 门控三态正确；
  进度泵冷启动守卫 + finally 取消。
- **BpTools 契约**：bp/wp length 恒下发（真机边界①）、rwp 无 all 形态走列出逐个删（真机边界③）。
- **CLI help**：burn/verify/rtt 的选项与退出码声明逐项一致（watch/doctor 见 A-6/A-7）。
- **文档对齐**：README 工具数 30 ✓、版本 0.4.30 ✓、SKILL.md 工具名/参数 camelCase ✓、
  watch 章节标 v0.4.3（确为首入版本，git 核过）✓；sync-local.ps1 已在 51ac233 有意删除（改走原生 CLI）✓。
- **e2e**：38 场景全绿，含 P0-3 边界、CRC INCONCLUSIVE、断链重放、rtt 三态。
